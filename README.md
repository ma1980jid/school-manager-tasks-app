# لوحة متابعة أعمال مدير المدرسة - النسخة الثالثة PWA

هذه النسخة مخصصة لاختبار التطبيق كتطبيق ويب يعمل على الهاتف والكمبيوتر، مع تجهيزات PWA للتثبيت على الشاشة الرئيسية.

## الجديد في النسخة الثالثة

- تجهيز PWA كامل عبر `manifest.webmanifest` و `sw.js`.
- أيقونات PNG و SVG للتثبيت على الهاتف.
- زر "طريقة التثبيت" مع تعليمات Android و iPhone.
- شريط اختصارات للهاتف: إضافة مهمة، اليوم، المتأخرة، نسخة احتياطية.
- مؤشر حالة الاتصال: متصل / بدون إنترنت.
- تحسينات إضافية لتجربة الهاتف.
- تحديث النسخة الاحتياطية إلى version 3.

## طريقة التشغيل على الكمبيوتر

من داخل مجلد التطبيق شغّل:

```bash
python -m http.server 8080
```

أو إذا كان الأمر `python` غير معروف:

```bash
py -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

> ملاحظة: يمكن فتح `index.html` مباشرة للتجربة، لكن خصائص PWA والتثبيت تحتاج `localhost` أو رابط HTTPS.

## التثبيت على الهاتف

بعد رفع التطبيق على رابط HTTPS:

### Android / Chrome
1. افتح رابط التطبيق في Chrome.
2. اضغط زر "تثبيت التطبيق" إن ظهر.
3. أو من قائمة ⋮ اختر "إضافة إلى الشاشة الرئيسية".

### iPhone / Safari
1. افتح رابط التطبيق في Safari.
2. اضغط زر المشاركة.
3. اختر "إضافة إلى الشاشة الرئيسية".

## الخصوصية في هذه النسخة

- لا توجد قاعدة بيانات خارجية.
- البيانات تحفظ في متصفح الجهاز أثناء التجربة.
- يمكن تصدير نسخة احتياطية JSON واستيرادها.
- ربط Microsoft / OneDrive سيضاف في مرحلة لاحقة بحيث تحفظ بيانات المدير داخل حسابه.

## ملفات مهمة

- `index.html`: واجهة التطبيق.
- `styles.css`: تنسيقات الواجهة.
- `app.js`: منطق التطبيق وحفظ البيانات.
- `manifest.webmanifest`: تعريف PWA.
- `sw.js`: التخزين المؤقت للتطبيق.
- `icons/`: أيقونات التطبيق.
