# نظام الاستعلام عن بيانات الطالب

مدرسة الشيخ حمدان بن خميس اليوسفي

## فكرة النظام
واجهة عربية متجاوبة للبحث عن بيانات الطالب بالاسم، مع تنفيذ البحث عبر API على الخادم بدل تخزين قائمة الطلاب داخل ملف JavaScript العام.

## بنية المشروع

- `public/index.html` واجهة الاستعلام.
- `public/style.css` التصميم المتجاوب.
- `public/script.js` الاتصال بخدمة البحث.
- `server.js` خادم Node.js وواجهة API.
- `data/students.example.json` مثال فقط لبنية البيانات.
- `data/students.json` ملف محلي اختياري للبيانات الحقيقية، وهو مستبعد من Git عبر `.gitignore`.

## صيغة بيانات الطلاب

```json
[
  {
    "name": "أحمد محمد سالم الحارثي",
    "grade": "السابع",
    "section": "7/1"
  }
]
```

## التشغيل محليًا

```bash
npm install
npm start
```

ثم افتح:

`http://localhost:10000`

## البيانات على Render

الخدمة تقرأ البيانات بأحد الخيارين:

1. متغير البيئة `STUDENTS_JSON` ويحتوي مصفوفة JSON.
2. ملف محلي خاص باسم `data/students.json` أثناء التطوير.

لا تضع بيانات الطلاب الحقيقية في مستودع عام.

## إعداد Render

يوجد في جذر المستودع ملف `render.yaml` جاهز لإنشاء Web Service باسم:

`hamdan-yousufi-students`

ومجلد الجذر للخدمة:

`hamdan-student-inquiry`

بعد ربط المستودع بـ Render، أدخل قيمة `STUDENTS_JSON` عندما يطلبها Render أثناء إنشاء الـ Blueprint.

## الشعار

`public/logo.svg` شعار مؤقت فقط. يستبدل لاحقًا بالشعار الرسمي للمدرسة مع تعديل مسار الصورة في `public/index.html` إذا لزم.
